# Interactive-Sales-Dashboard
Interactive Sales Dashboard (Mini EDA Project)

This project demonstrates the end-to-end creation of an interactive Sales Dashboard in Excel using Power Query, Power Pivot, PivotTables, and PivotCharts.

🔑 Key Features:

Data Preparation: Imported and combined multiple CSV files via Power Query with automated refresh.

Data Cleaning & Transformation: Calculated Sales Amount, Days to Ship, and applied proper data types.

Data Modeling: Built a star schema with fact and dimension tables, defined relationships, and created DAX measures.

Interactive Visuals:

Sales by Category & Salesperson

Sales Trends over Time

Shipping Metrics & Days to Ship

KPI Cards and optional Map Charts

Sparklines for Top Customers/Products

Dashboard Interactivity: Added slicers (Category, Region, Month, Customer) connected across all visuals.

Auto Refresh: Supports automatic data updates when new files are added to the source folder.

💼 Corporate Use Case: A sales team can track KPIs, customer trends, shipping performance, and category-level insights with minimal manual effort.
